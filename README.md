# Notes
Questa repository contiene tutti i miei appunti universitari.

Nota per l'uso: ogni cartella contiene un file Appunti.pdf che e' il compilato finale su cui si puo' studiare e un directory "data" con tutti i file necessari alla compilazione. Nel caso si volessero apportare modifiche bisogna modificare il file main.tex e una volta ultimata la modifica eseguire il comando "latexmk -auxdir=. -outdir=.. -pdf -jobname=Appunti main.tex" per generare il pdf coerentemente all'organizzazione di questa repository.
